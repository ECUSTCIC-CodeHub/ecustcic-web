# 图书数据库的使用

# 校内数据库

华东理工大学有丰富的电子数据库资源，主要包括图书馆数据库和商学院的自购数据库。

  • 商学院的自购数据库：https://bslab.ecust.edu.cn/datasources.html (opens new window)
  • 图书馆数据库：https://wisdom.chaoxing.com/newwisdom/doordatabase/database.html?pageId=711057&wfwfid=27830&websiteId=410556&uid=101458310&mhEnc=0575199afdb83118a95c4b6363503a15&publicId=89e89a7e5269c111ee28d7c8955d456b6891&typeId=13343052 (opens new window)

# 校外访问

  • 可使用学校 SSL VPN 访问校内资源：https://sslvpn.ecust.edu.cn (opens new window)
  • 如需外文资源则还可以考虑注册上海图书馆 (opens new window)等。
