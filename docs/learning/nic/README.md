# NIC 域名分发系统

CIC 面向校内同学提供免费域名分发服务，你可以为自己的项目申请一个专属域名。

🔗 **控制台地址**：<https://nic.ecustcic.com/>

## 可用根域名

| 根域名 | 说明 |
|---|---|
| `cic.su` | 苏联域名 |
| `cic.cool` | 这个域名很酷😎 |

你可以在此基础上申请如 `your-project.cic.su` 或 `your-project.cic.cool` 的子域名。

## 使用方法

1. 前往 [ECUSTMC 皮肤站](https://mcskin.ecustvr.top/) 登陆/注册账号
2. 登录 [NIC 域名分发系统](https://nic.ecustcic.com/)（通过 ECUSTMC 站验证登录）
3. 选择根域名，填写你想要的子域名前缀
4. 配置 DNS 解析记录（A / CNAME / TXT 等）
5. 提交申请，等待审核通过后即可使用，审核结果会通过邮箱通知

## 注意事项

- 本服务仅限校内人员使用
- 域名需合理使用，不得用于违法违规内容
- 长期未使用的域名可能会被回收
- 如有问题，欢迎在社团群内反馈
