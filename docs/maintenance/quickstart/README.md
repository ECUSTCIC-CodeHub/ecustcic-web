# 本站维护快速入门指南

## 关于本站

这是一个基于 Vue 2 的文档站点，支持 Markdown 文件加载。

### 功能特点

- 支持加载外部 Markdown 文件
- 实时预览
- 响应式设计
- 左侧导航菜单

### 使用方法

1. 在 `public/docs` 目录下创建 Markdown 文件
2. 在 `src/data/menu.js` 中添加菜单项
3. 提交代码，部署后即可访问
